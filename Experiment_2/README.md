# Experiment 2 — Kathakali DWPose Extraction

## Dataset
- 41 Kathakali classes
- 430 source videos
- 100 sampled frames per video
- 50 selected joints per frame
- X, Y coordinates and confidence scores

## Structure
- dwpose/implementation: DWPose code and model weights
- dwpose/old_archive: Previous 110-file pose datasets
- dwpose/extracted_430: Fresh extraction output
- scripts: Extraction scripts
- logs: Extraction logs
- metadata: Extraction manifests
